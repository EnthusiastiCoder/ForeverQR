An email QR code saves people from typing your address. They scan it, their mail app opens a new message addressed to you, and all they have to do is write and send. It works well anywhere a printed address would be awkward.

## How to make one

1. Enter the address that should receive the mail.
2. Add a subject if you want replies to be easy to sort, such as "Booking enquiry" or "Poster feedback".
3. Add a starting message in the body if useful, for example "Hello, I would like to know more about...".
4. Download the code and put it where people will see it.

## Good uses

Feedback cards, shop counters and flyers for local services work well. A conference slide with a code that opens a message with your name in the subject is quicker than asking people to write down an address. Landlords, freelancers and small clubs all use them for first contact.

## A word on spam

Anything on a public poster can be read by software as well as people. Spam robots scan images too, though far less than they scrape web pages. Use a dedicated address for public codes, and use a different one for private mail, so you can filter or retire it if it ever gets noisy.

## No middleman

The address, subject and body are stored in the square, using the standard mailto format. Nothing depends on our servers or anyone else's, so the code keeps working as long as the mailbox does. There is no scan counter and no dashboard, because we cannot see who scans it.

## Keep it readable

A short subject and body make a simpler pattern that is easier for a camera to read. A long pre-written message creates a dense code, and the scan badge in the studio will tell you if it is getting hard to read. In that case shorten the text or print the code larger.

## Your data stays with you

The form is processed in your browser. The address you type is never sent to this site or anywhere else, and the page makes no outside requests. See the [privacy page](/privacy/) for what is stored locally, and how to clear it.
