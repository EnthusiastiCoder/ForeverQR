A location QR code opens a map pinned to exact coordinates. It is ideal when an address is vague or missing: a trailhead, a field entrance, a market stall, a meeting spot in a park, or a building whose street number is hard to find. People scan, their map app opens, and they can start navigating.

## How to make one

1. Find the coordinates of the spot. Long-press a point on your phone's map app, or right-click it on a desktop map, and copy the two numbers.
2. Enter the latitude and longitude. Latitude runs from -90 to 90 and longitude from -180 to 180. The studio tells you if a value is out of range.
3. Check the preview, then download the code as SVG for print or PNG for screens.

## Why coordinates beat an address

Street addresses can be ambiguous, duplicated between towns, or missing altogether in rural areas and new developments. A pair of coordinates points to one place. For a festival field, a car park or a campsite pitch, that precision removes the usual "we are by the red gate" phone call.

## What happens on the phone

The code uses the geo format, which phones pass to their default map app. On most devices that shows a pin and offers directions. Some desktop programs do not handle the format, so for codes aimed at laptops you might prefer a [URL code](/url-qr-code-generator/) linking to a map page.

## Permanent, with a caveat

The point is stored inside the pattern, so the code never depends on a website. It stays valid as long as the place does. If the entrance moves or the event ends, the code will still send people to the old spot, so use it for fixed places and reprint if things change.

## Privacy

Your coordinates are turned into a code in your browser and not uploaded. Be thoughtful about publishing a code that marks your home or a private spot, because anyone who scans it learns the location to within a few metres. The [privacy page](/privacy/) explains what the site stores and what it does not.

## Printing advice

Add a short caption, such as "Scan for the exact meeting point", so people know what the square does. Keep the border around the code, use dark dots on a light background, and print it at least two centimetres across. For a sign people will read from a distance, go much larger, then try it yourself from where they will stand.
