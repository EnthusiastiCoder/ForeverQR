A WiFi QR code lets guests join your network by pointing their phone camera at it. No spelling out a long password, no typos, no asking again next time. Fill in the form above and the code updates as you type.

## How to make one

1. Enter the network name exactly as it appears on a phone, including capitals and spaces. This is case sensitive.
2. Choose the encryption. Most modern routers use WPA or WPA2, which is the default here. Choose "none" only for an open network.
3. Type the password. If your network is hidden, tick the hidden network box so phones know to look for it.
4. Download the code and print it, or save it to your phone and keep it handy.

## Where it works

Current iPhones and Android phones read WiFi codes from the normal camera app and offer to join. Some older phones need a QR reader app. Windows laptops generally cannot join from a code directly, though they can display the password after a phone reads it.

## Keeping it private

Your password is sensitive, which is why the studio never sends it anywhere. The page works fully offline once it has loaded, so you can even turn off your connection while making the code if you want to be sure. Saved settings stay in your own browser, and the Reset button wipes them.

A printed WiFi code gives the password to everyone who sees it, so think about where it hangs. A frame in a rental flat or a card in a guest room is fine. A poster in a public window is not. If you run a cafe, consider a separate guest network with its own password, so changing it never disturbs your own devices.

## Make it look right

Dark dots on a light background scan best. You can add your colours, a rounded style or a small logo, and the scan badge tells you at once if a choice makes the code harder to read. Print it no smaller than two centimetres, and add the words "Scan to join WiFi" beneath, since people do not always know what a square means.

## Why a static code

The network name and password sit inside the square. Nothing depends on a website or a subscription, so the code works as long as the router settings stay the same. That is the point of ForeverQR: you print it once and forget it.
