A text QR code holds plain words: a message, a serial number, a poem, a licence key, a short set of instructions. When someone scans it, their phone shows the text. It never needs a network, a server or a subscription, because the words are stored right in the square.

## How to make one

1. Type or paste the text into the box. Line breaks are kept.
2. Watch the scan badge. Longer text makes a denser pattern that is harder for cameras to read.
3. Download as SVG for print, PNG for a screen, or PDF for a printed page.

## What it is good for

Text codes are handy in places where there is no internet, or where you do not want to depend on one. Labels on equipment can carry a serial number or a short instruction. A museum card can hold a quote. A party game can hide a clue. A teacher can put a worked answer on the back of a worksheet. The reader sees the text immediately without loading a page.

## How much is too much

The format can hold nearly three thousand characters, but a camera has to resolve every dot, and a very full code needs to be printed large and scanned in good light. For anything longer than a few lines, put the words on a page and use a [URL code](/url-qr-code-generator/) instead. The studio can raise the error correction when it needs more room for the pattern, and tells you when it does.

## Not a secret

Nothing in a QR code is hidden. Anyone with a camera can read it, so never encode a password for something you would not shout across a room. For a WiFi password use the [WiFi generator](/wifi-qr-code-generator/), and think about where the printed code will hang.

## Private and permanent

The text is turned into the code in your browser. It is not uploaded, logged or counted, and the page makes no requests to any other site. Because there is no server in the loop, the code does not expire. If the text itself goes out of date, make a new code.

The [privacy page](/privacy/) explains what the site stores on your device, and how to clear it with the Reset button.

## A few ideas

Try a text code for a shelf label that tells a volunteer what goes where, a spare-key hint, or the answer to a riddle in a treasure hunt. Because the words need no network, they work in a cellar, on a boat or at a festival with no signal.
