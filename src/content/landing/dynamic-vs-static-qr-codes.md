People use "dynamic" and "static" for QR codes as if everyone agrees on the meaning, and then buy the wrong one. This page sets out what each does, what it costs and where each fits, using the vendors' own words where they describe their own products.

## Static codes

A static code encodes the final content directly: the web address, the WiFi details, the contact card. The pattern of dots is the data. Once made, it cannot be edited, and it cannot be switched off, because nothing outside the square is involved. No account is needed to keep it alive.

## Dynamic codes

A dynamic code encodes a short address on the vendor's domain. When scanned, the phone visits that address, and the vendor's server redirects it to the real destination. That detour is what makes editing and statistics possible. Vendors describe this in their own help pages, and terms differ and change. Before you buy, open the help centre of the vendor you are considering and search it for "dynamic QR code", "redirect" and "expire", and read what happens to your code when the plan ends. We have not summarised any one vendor's terms here, so that nothing on this page goes out of date.

## Side by side

| | Static | Dynamic |
| --- | --- | --- |
| Content stored | In the code | On the vendor's server |
| Editable after printing | No | Yes |
| Scan statistics | No | Usually yes |
| Works without the vendor | Yes | No |
| Typical cost | Free | Often a subscription |
| Privacy | Nobody sees scans | The vendor sees each scan |

## The trade-off in plain terms

With a dynamic code you rent a promise: the vendor will keep the redirect running. You gain the ability to change your mind and see how many people scanned. You lose permanence and some privacy. When a plan ends, vendors differ in what happens, but a stopped redirect leaves a printed code dead.

With a static code you own the result. It cannot be edited, but it also cannot be taken away. If you need an editable destination, there is a way to get most of that without renting: point a static code at an address on a domain you control, and change where that address redirects.

## Which to choose

Choose static for menus, packaging, signs, business cards, WiFi, contact details and anything printed in bulk. Choose dynamic only for short campaigns where you need to measure scans and can afford to maintain the code.
