An event QR code adds a date to someone's calendar in one scan. Put it on an invitation, a poster or a ticket, and people no longer have to copy the time and place by hand, or forget it altogether. It reads from the normal camera app and opens the phone's calendar with the entry ready to save.

## How to make one

1. Give the event a clear title, such as "Garden Club summer fair".
2. Set the start and end, and choose the time zone the event happens in. Tick "All day" for events without set hours.
3. Add the location and a short description, such as a door code or what to bring.
4. Check the preview and download the code.

## Why it works well on paper

Invitations and posters get glanced at weeks before the day. A calendar entry is a reminder that lives on the phone, with the place attached. It is much more likely to be seen on the day than a number in a paragraph. Clubs, schools, local councils, weddings and conferences all use them for exactly this reason.

## The details that matter

- Time zones: choose the zone where the event takes place. Guests travelling from elsewhere will see the correct local time.
- Length: the description is stored inside the code. A long one makes a dense pattern, so keep it to a sentence or two and put the rest on a web page.
- Accuracy: double-check the date before printing. The code is permanent, and a wrong date is wrong forever.

## When plans change

A static code cannot be edited. If the event moves, print a new one and cover or replace the old. If the date is uncertain or likely to shift, point people to a page you can update using a [URL code](/url-qr-code-generator/) instead, which stays correct as you edit the page.

## No accounts, no tracking

The event is turned into a code in your browser. Nothing is uploaded, and there is no scan counter, because the code does not pass through our servers. It uses the standard calendar format, so it works with the calendar apps people already have, and it keeps working as long as the date matters.

## Print it where people will look

Place the code next to the date on the poster, with a few words such as "Scan to add to your calendar". People who see the words first scan more often, and a short caption costs you nothing.
